# TrustVault – AI Prompts Documentation

## 1. Project Overview
TrustVault is a secure document management system developed using Python, Django, HTML, and SQLite.

## 2. Prompts Used During Development

### Prompt 1: Project Setup
Help me create a document management system using Python and Django.

### Prompt 2: Document Upload
Create a Django feature that allows authenticated users to upload documents and save their details in a database.

### Prompt 3: Document Download
Implement secure document downloading so that only the owner or an authorized user can download a document.

### Prompt 4: Document Deletion
Implement a feature that allows document owners to delete their own documents.

### Prompt 5: Document Sharing
Create a feature that allows a document owner to share a document with another registered user.

### Prompt 6: User Authentication
Implement user login and protect document-management pages so that only authenticated users can access them.

### Prompt 7: Access Control
Ensure that users cannot download or delete documents without the required permissions.

### Prompt 8: Debugging
Help identify and fix Django errors related to URL routing, templates, file uploads, and document sharing.

## 3. Testing
Test document upload, download, deletion, sharing, login, and access permissions using separate user accounts.

## 4. Responsible AI Use
AI assistance was used to understand Django concepts, troubleshoot errors, and develop features. The project code should be reviewed and tested to ensure it works correctly.
